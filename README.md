# 🌌 Interactive Universe Sandbox Web Application

A lightweight, real-time interactive browser gravity sandbox built entirely with raw standard frontend components (**HTML5 canvas**, **CSS3 variables layout structure**, and vanilla **custom vector physics Javascript mechanics**).

## 🚀 Live Demo & Installation

To run this simulation environment locally without complex package builders:
1. Clone this repository locally:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the root directory folder layout.
3. Open the `index.html` file inside any modern browser viewport interface (Chrome, Safari, Firefox, or Edge support it out of the box).

## 🪐 Feature Capabilities

- **Orbital Vector Slinger Integration Engine:** Clicking and dragging allows you to project planetary items across custom speed limits using adaptive mouse mechanics.
- **Dynamic Orbital Mergers:** Collision systems compute proportional momentum conservation parameters (\(m_1v_1 + m_2v_2 = m_{total}v_{final}\)). Heavier masses organically consume intersecting paths!
- **Control Customization Dashboard:**
  - Adjust global Universal Gravitation Constant values dynamically.
  - Slow down, speed up, or pause absolute runtime parameters completely.
  - Trace trajectories using real-time canvas paths or deploy cosmic coordinate reference grids.
- **Preconfigured Solar Setup System:** Load structured orbital models rapidly to benchmark gravity dynamics.
